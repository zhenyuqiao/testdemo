# 冰箱新产品性能开发 · 交互流程图

聚焦冰箱新产品性能开发，展示从需求接收到方案定版的完整流程、主要时间消耗、返工回路、当前工具与 AI 探索机会。

## 本地运行

```bash
npm install
npm run dev
```

默认在 `http://127.0.0.1:4821` 打开。

```bash
npm run build
npm run preview
```

## 页面内容

- **六步主流程**：需求 → 方案 → 协调 → 样机 → 实验 → 分析决策
- **两类迭代回路**：参数级调参与方案级返工
- **时间消耗视图**：定性标识主要耗时压力，不虚构实际工时
- **当前工作方式**：个人知识库、Excel、经验公式、第三方测试软件、电控调参工具
- **AI 机会视图**：知识沉淀、约束检查、实验设计、智能调参与数据闭环

点击任一流程节点可查看参与角色、当前工具、痛点与 AI 探索机会。
