冰箱研发流程离线阅读页：

- `ice_program_flow.html`：**冰箱研发全流程沙盘**（汇整控制程序 + 项目管理指南；主线含平台/企划/方案/试制试产投产/上市，并嵌套分流程与输入输出）
- `ice_new_program_flow.html`：QMB-GB.0025-2025《新产品设计开发控制程序》阅读指南
- `ice_program_manager.html`：冰箱项目管理流程指南（12.xlsx 工作表归纳）
- `fridge-perf-flow/`：**新产品性能开发交互流程图**（React/Vite；含时间消耗、返工回路与 AI 机会）

本地直接用浏览器打开对应 HTML 即可（离线可用）。`fridge-perf-flow` 需先安装依赖再启动：

```bash
cd fridge-perf-flow
npm install
npm run dev
```
