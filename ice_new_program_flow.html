01 / SOURCE

先确定文件定位

这不是对Excel流程分权表的重述，而是对正式企业标准 QMB-GB.0025-2025《新产品设计开发控制程序》 的阅读辅助。它管的是冰箱事业部新品从单产品规划到项目结项的过程角色、责任、周期、转阶段规则和考核要求。

控制边界

覆盖单产品规划、方案设计、产品试制、产品试产、投产鉴定、上市决策、产品退市；销售与客户服务另有管理办法。

上市决策

PDF明确：产品企划应在产品规格书要求的计划时间前提交上市决策流程。

整理说明：上市决策不是投产鉴定的同义词；投产鉴定是开发和制造准入，上市决策是产品进入市场前的决策节点。

03 / TAILORING

项目等级决定流程深度

项目等级按结构、性能、电控、外观四个维度的全新开发程度和综合难度划分。最终等级以开发立项等级为准，变更等级需在GPM系统走等级变更流程；升级后按新等级增删流程任务。

等级PDF定义执行含义
T类结构、性能、电控、外观中有三个或三个以上全面全新开发。完整度和评审深度最高，关键专业评审和里程碑通常均为必选。
I类上述四个维度中有两个全新开发，或相当于此类难度。基本沿用T/I类完整技术评审和综合方案评审要求。
II类上述四个维度中有一个全新开发，或相当于此类难度。对新开发或变更专业模块必须评审；部分专业交付可按表格裁剪。
III类已有机型基础上的派生产品，结构、性能、电控、外观有部分变更，或相当于此类难度。重点验证变更内容；无开模项目可能减少样机、评审和试制节点。
PDF明确：单专业开发难度高、验证周期长的项目可以申请升级；在满足技术开发难度等级的前提下，只允许升级，不允许降级。销售区域变化要重新综合评估，外销OEM转内销还需补做内销相关用户研究、体验、基本性能、可靠性和安全安规等项目。

05 / DESIGN

方案阶段：把概念变成可评审、可制造、可验证的方案

方案阶段以项目经理为主要负责人。原则上，所有技术方案调整、改善或更改需求应在本阶段提出；综合方案评审之后再新增的技术变化，必须按变更规则处理。

输入 立项、计划和产品规格

产品企划在MPLM创建正式产品规划书，项目经理据此开发立项、组建团队、召开项目启动会，输出《项目启动会会议纪要》和《项目WBS计划》。T/I类项目在单产品规划阶段还需组织MIS工作坊，并在综合方案评审时对设计MIS会议纪要形成闭环结论。

来源：PDF第9页6.2.1、第20页6.7.1。

专业设计 结构、性能、电控、电器、包装和专利

各专业开展方案设计和DFMEA，并组织可靠性、用户体验、工艺、品质、模具工艺、供应链等参与评审。结构方案评审完成后图纸设计发放，再按MIS2/MIS3和模具规则启动开模。产线技改需求最迟在MIS3预评审确认，试制样机需上大线验证适配，试产前完成技改。

来源：PDF第9页6.2.2。

可靠性与专利 先过专项门，再进综合方案评审

T/I类强制输出可靠性五大交付：企划书可靠性必填项、可靠性规划书、可靠性试验方案、产品设计规格书、FBD及线上DFMEA分析报告；II类不强制输出FBD及DFMEA。可靠性评审通过后方可进入综合方案评审。专利工程师需完成客观检索、核心专利定义、《专利布局清单》和《专利评估报告》。

来源：PDF第9–10页6.2.3–6.2.4。

手板与模具 评审、测试、供应商和首样同步推进

II类及以上全新开发项目需做可制造性评审；II类及以上需做存储运输、安装维修性评审。方案阶段由研发主导手板摸底测试，由项目组、设计可靠性和品质共同确认方案，用户研究主导体验测评。模具立项后3天内确定开模厂（紧急项目2天），招标后3天完成模具方案初稿、7天锁图，模具到制件厂3天内试模打样。

来源：PDF第10–11页6.2.6–6.2.8。

综合方案评审 方案阶段的冻结和转阶段判断

设计可靠性专家预审综合方案评审资料。会议重点复盘摸底测试与规格书、各专业问题、成本达标、专利布局；A类问题必须关闭，否则不得进入下一阶段。A类及重点B类问题的失败案例按要求转化为失败案例，基本性能应优于竞品或现有平台产品。

来源：PDF第11页6.2.9–6.2.10。

各环节输入、产物和附件关系

01 立项启动：把正式规划书转成可执行开发计划

输入：产品企划通过产品策划决策后，在MPLM创建的正式产品规划书；其中应能看到产品定位、项目等级、基本性能目标、可靠性目标、成本/毛利、上市/批产计划、销售区域和开发约束。若属于平台或模块开发，还要识别平台需求、接口和复用边界。

02 设计输入展开：将规划目标拆成专业方案

输入：正式产品规划书、设计目标、工业设计需求、平台规格和接口、模块需求、适用设计标准、历史相似产品问题、竞品信息，以及项目等级对应的评审深度。

06 / TRIAL BUILD

产品试制：验证设计方案，而不是提前量产

试制重点验证产品方案，由研发项目组主导；为确保有效性，必须由生产线员工组装。试制申请前要完成E-BOM设计发放、测试方案和样机数量确定，工厂在申请完成后10天内完成试制。

控制点程序要求时限/证据
物料准备所有物料正式试制前1天到位；研发提供借用物料和新增物料清单；新增外协物料提前2天进中试仓库。清单、供方资质/制件厂家确认、到位记录。
上线前确认试制前1天共同试装空箱体，确认物料齐套、基本装配、发泡前条件。预装配、小件部装、总装物料汇总确认。
上线试制分厂按计划刚性执行；研发主导，各专业协同，生产线员工参与，周期原则上不超过10天。试制记录、装配问题记录。
问题收集下线后2天内召开装配小结，将技术、工艺、电控、测试、设备工装、质量和文件问题录入PLM问题模块，并现场判定责任方。PLM问题记录、责任判定、整改方案。
测试与测评样机下线后1天内送样；测试完成后2天内出具《整机测试报告》；T/I/II类进行五感评审。性能、结构、五感、安规安全等测试/评审报告。
样机鉴定整改后评审样机或零部件状态；发泡Q评价合格，A类问题100%关闭，产品合规性评审合格。样机鉴定结论；同时满足转试产前置任务、测试合格和BOM完成制造发放。
试制转试产的硬条件：A类问题必须关闭；试制阶段测试完成且合格；问题项有整改方案；BOM完成制造发放。正式程序的修订说明特别强调了“样机鉴定前需BOM完成制造发放”。

来源：PDF第12–16页6.3.1–6.3.7及试制阶段总体要求表。

07 / PILOT RUN

产品试产：验证生产组织与量产可行性

试产重点验证产品生产组织，由首产地工程部主导，研发项目经理协助，按《试产SOP》执行；生产线员工必须参与组装。

阶段必须完成的工作程序中的关键约束
试产申请根据试制验证修正设计发放版本，完成M-BOM制造发放；归档电控、工艺、质控交底和供方装配指引；制定试产测试方案。M-BOM在转试产前完成；特殊未引入物料可线下清单确认，但投产鉴定前必须补齐BOM。
物料准备试产上线前1天完成配套；开发工程师确认，工厂进货检验合格后上线。禁止项目工程师直接带物料上线；按试制整改后的状态试产。
正式试产上线前1天确认空箱体、零部件齐套、发泡及总装条件；各专业到场跟进；样机由线体员工制作。试产作业刚性执行，原则上周期10天；异常由新品工艺协调记录并按责任主体追溯。
测试与问题整改进行性能、结构、五感、可靠性、安规安全等测试；问题录入PLM；下线后3天内完成BOM一致性确认和装配小结。不合格按要求整改；试产测试合格报告应在实验完成后1天内上挂。
物料封样依据问题关闭逐步完成整机BOM物料100%封样。二次试产按需执行；T/I/II/III开模项目最后一次试产要求100%正式封样。
投产鉴定准备归档说明书、维修手册、爆炸图、认证报告、整机测试报告、电控资料、可靠性更新、“四新”设计规范和降额评审报告。投产鉴定前完成前置任务、问题关闭、正式样品确认、测试合格和失败案例转化确认。
首批产：项目完成投产鉴定后，工厂需在15天内完成首批产。随后由项目经理提交项目结项流程完成结项。
延期与产出 延期考核及试制/试产产出核算

类别含义影响
